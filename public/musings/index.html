Tools I Enjoy Using

Being a university student studying both mathematics and computer science, as well as someone who works full time, the tools I use everyday are vital to my success in both school and life. This is even more important for me as I have Bipolar disorder and Autism. Here are some of my favorite tools that I use every day. Nix While Homebrew is the conventional pick for a package manager on macOS, I would argue that Nix is the better option. The key reason is reproducability, which means that if I have to wipe my laptop or I get a new machine, I can quickly bootstrap a new system since I have all my settings/options preconfigured. Nix also allows you to manage any Homebrew packages you need, which is my preferred method. The X-Factor of Nix however is that you can specify a “development shell” which contains packages/utilities that you only need for one program, which is great for keeping your machine clean and free from package bulk. ...
